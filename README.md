# Overlay Teclado · v1.0.0

Overlay transparente de **teclado, mouse y mandos** (Xbox, PS4, PS5 y mandos compatibles). Solo para **Windows**.

## Instalar

1. Instala **Python** desde [python.org](https://www.python.org/downloads/) (activa **Add Python to PATH**).
2. Ejecuta uno de los instaladores y confirma con **S**:
   - Python **3.14** → `script-instalacion/Python_3.14/INSTALAR.cmd`
   - Python **3.13 o anterior** → `script-instalacion/Python_3.13_o_inferior/INSTALAR.cmd`
3. Abre `overlay_teclado_v1.0.0.pyw` (o ejecuta `py overlay_teclado_v1.0.0.pyw`).

Conserva la carpeta `assets/` junto al `.pyw`. Los instaladores comprueban cada biblioteca antes de descargarla.

## Usar

- **F8:** mover/fijar overlay; arrastra la esquina para redimensionar.
- **Ctrl+Alt+H:** ocultar/mostrar sin cerrar.
- **Ctrl+Alt+O:** abrir ajustes: opacidad, temas, atajos, vista y tamaño.
- **Bandeja del sistema:** ajustes, vista, tamaño, visibilidad y salir.
- **Clic derecho** con el overlay en modo mover: cerrar.

Los atajos se pueden cambiar. Los ajustes se guardan en archivos locales y **no** se inicia automáticamente con Windows. Solo se permite una instancia del programa.
